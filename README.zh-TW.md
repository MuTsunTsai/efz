# ETERNAL FIGHTER ZERO Web

[English](README.md) | **正體中文** | [日本語](README.ja.md)

在瀏覽器中遊玩 ETERNAL FIGHTER ZERO 的非官方移植版。

**本程式不附帶任何遊戲資料。** 遊玩前，你需要自備 ETERNAL FIGHTER ZERO **4.02 版**的遊戲資料夾。

## 開始遊戲

1. 開啟網頁，按「選擇遊戲資料夾」，選取含有 `efz.exe` 與 `system` 目錄的 EFZ 遊戲資料夾；也可以直接把資料夾拖曳到網頁上。
2. 第一次選擇後，遊戲檔案會存放在這個瀏覽器中。之後再開啟網頁，直接按「開始遊戲」即可，不必重新選擇資料夾。
3. 載入過一次之後，即使沒有網路連線也能遊玩。
4. 也可以用瀏覽器的「安裝應用程式」或「加到主畫面」功能，把它安裝成獨立的 App。

要刪除存放在瀏覽器中的遊戲檔案，請在啟動頁按「清除已儲存的遊戲資料」。

網頁會依瀏覽器的語言設定，自動以正體中文、日文或英文顯示。

### 注意事項

- 請使用最新版本的 Chrome、Edge 或 Firefox 等桌面瀏覽器。
- 只支援 4.02 版的遊戲資料；使用其他版本的檔案可能發生不可預期的行為。
- 瀏覽器無法寫回你的遊戲資料夾，所以遊戲內的設定、戰績與新錄製的錄影都只存放在這個瀏覽器中，不會改動原本的檔案。清除瀏覽器的網站資料時，這些內容也會一併刪除。
- 如果資料夾中有 `key.ini`，會沿用其中的按鍵設定。
- 本移植的遊戲邏輯是按照原版 4.02 實作的，沒有套用 EFZ Revival 對遊戲所做的修改（例如同時按左右時的優先順序、部分變數的初始化、效果設定的固定等）。
- 可以播放 EFZ Revival 錄製的錄影，但由於 Revival 錄製時套用了上述修改，播放結果可能與錄製當時的實際對戰不同。這與在沒有 Revival 的原版中播放時相同。

## 操作

### 預設按鍵

| | 上 | 下 | 左 | 右 | 弱 | 中 | 強 | Sp |
|---|---|---|---|---|---|---|---|---|
| 1P | Y | N | G | J | Q | W | E | D |
| 2P | ↑ | ↓ | ← | → | P | [ | ] | \ |

- 2P 的中／強／Sp 在原版的日文鍵盤上是 P 右邊連續三個鍵；在英文配列鍵盤上對應到 `[` `]` `\`。
- 支援搖桿（最多兩支），依 `key.ini` 的搖桿設定對應。
- ESC：在各畫面中返回上一層；在標題畫面結束遊戲並回到啟動頁。

### 觸控裝置（手機、平板）

- 啟動遊戲時會進入全螢幕，畫面配置會隨裝置方向改變。
- 在啟動頁勾選「顯示虛擬搖桿」（選擇會被記住）後，畫面上會出現半透明的搖桿：左下角是方向圓盤，右側四個按鍵為右：弱、上：中、左：強、下：Sp，左上角另有 ESC 鍵。
- 虛擬搖桿固定操作 1P，不受 `key.ini` 按鍵設定影響。
- 對戰中，右上角會依模式顯示目前可用的功能鍵按鈕（例如所有模式都有 F8 暫停，練習模式另有 F4～F7），作用與下方功能鍵相同。

### 功能鍵

| 按鍵 | 作用 | 可用時機 |
|---|---|---|
| F1 | 重新讀取 `key.ini` 的按鍵設定 | 任何時候 |
| F2～F4 | 切換到 `key.ini` 中的第 1～3 組按鍵設定 | 任何時候（`key.ini` 有設定時） |
| F4（按住） | 調整量表 | 對戰中（Arcade 以外的模式） |
| F5 | 切換量表與體力的測試數值 | 對戰中（Arcade 以外的模式） |
| F6 | CPU 姿勢切換（站立／跳躍／蹲下） | 練習模式 |
| F6 | 重新開始錄製 | 錄影模式的錄製中 |
| F7 | CPU 自動防禦開關 | 練習模式 |
| F8 | 暫停 | 對戰中 |

- 網頁的 F5 重新整理已停用，要重新整理頁面請按 Ctrl+R。
- F11（全螢幕）與 F12 維持瀏覽器原本的功能。
