# ETERNAL FIGHTER ZERO Web

[English](README.md) | [正體中文](README.zh-TW.md) | **日本語**

ETERNAL FIGHTER ZERO をブラウザで遊べる非公式の移植版です。

**本プログラムにはゲームデータは含まれていません。** 遊ぶには、ETERNAL FIGHTER ZERO **バージョン 4.02** のゲームフォルダをご自身でご用意ください。

## 遊び方

1. ページを開いて「ゲームフォルダを選択」を押し、`efz.exe` と `system` フォルダを含む EFZ のゲームフォルダを選択します。フォルダをページに直接ドラッグすることもできます。
2. 一度選択すると、ゲームファイルはこのブラウザに保存されます。次回からはページを開いて「ゲームを開始」を押すだけで、フォルダを選び直す必要はありません。
3. 一度読み込んだあとは、オフラインでも遊べます。
4. ブラウザの「アプリをインストール」や「ホーム画面に追加」で、独立したアプリとしてインストールすることもできます。

ブラウザに保存したゲームファイルを削除するには、起動ページの「保存したゲームデータを削除」を押してください。

ページはブラウザの言語設定に合わせて、日本語・繁体字中国語・英語のいずれかで自動的に表示されます。

### 注意事項

- Chrome、Edge、Firefox などのデスクトップブラウザの最新版をお使いください。
- 対応しているのはバージョン 4.02 のゲームデータのみです。他のバージョンのファイルを使用した場合、予期しない動作が発生する可能性があります。
- ブラウザから元のゲームフォルダに書き込むことはできないため、ゲーム内の設定・戦績・新たに録画したリプレイはこのブラウザ内にのみ保存され、元のファイルは変更されません。ブラウザのサイトデータを削除すると、これらも一緒に削除されます。
- フォルダ内に `key.ini` がある場合は、そのキー設定を使用します。
- この移植版のゲームロジックはオリジナルのバージョン 4.02 に基づいており、EFZ Revival によるゲームへの変更（左右同時入力時の優先順位、一部の変数の初期化、エフェクト設定の固定など）は適用していません。
- EFZ Revival で録画したリプレイも再生できますが、Revival は録画時に上記の変更を適用しているため、再生結果が録画時の実際の対戦と異なる場合があります。これは Revival を使わないオリジナル版で再生した場合と同じです。

## 操作方法

### 初期キー設定

| | 上 | 下 | 左 | 右 | 弱 | 中 | 強 | Sp |
|---|---|---|---|---|---|---|---|---|
| 1P | Y | N | G | J | Q | W | E | D |
| 2P | ↑ | ↓ | ← | → | P | [ | ] | \ |

- 2P の中・強・Sp は、原作では日本語キーボードの P の右隣に並ぶ 3 つのキーです。英語配列のキーボードでは `[` `]` `\` に対応します。
- ゲームパッド（最大 2 台）に対応しています。割り当ては `key.ini` のゲームパッド設定に従います。
- ESC：各画面では前の画面に戻り、タイトル画面ではゲームを終了して起動ページに戻ります。

### タッチデバイス（スマートフォン・タブレット）

- ゲーム開始時に全画面表示になり、画面レイアウトは端末の向きに合わせて変わります。
- 起動ページで「仮想パッドを表示」にチェックを入れると（設定は記憶されます）、半透明の仮想パッドが表示されます。左下が方向パッド、右側の 4 つのボタンは右：弱、上：中、左：強、下：Sp で、左上には ESC ボタンがあります。
- 仮想パッドは常に 1P を操作し、`key.ini` のキー設定には影響されません。
- 対戦中は、右上にそのモードで使えるファンクションキーのボタンが表示されます（例：全モードで F8 ポーズ、トレーニングモードではさらに F4～F7）。機能は下記のファンクションキーと同じです。

### ファンクションキー

| キー | 機能 | 使用できる場面 |
|---|---|---|
| F1 | `key.ini` のキー設定を読み込み直す | いつでも |
| F2～F4 | `key.ini` の第 1～3 組のキー設定に切り替える | いつでも（`key.ini` に設定がある場合） |
| F4（長押し） | ゲージを調整する | 対戦中（Arcade 以外のモード） |
| F5 | ゲージと体力のテスト値を切り替える | 対戦中（Arcade 以外のモード） |
| F6 | CPU の姿勢を切り替える（立ち／ジャンプ／しゃがみ） | トレーニングモード |
| F6 | 録画をやり直す | リプレイモードの録画中 |
| F7 | CPU の自動ガードを切り替える | トレーニングモード |
| F8 | ポーズ | 対戦中 |

- ページの F5（再読み込み）は無効にしています。ページを再読み込みするには Ctrl+R を押してください。
- F11（全画面表示）と F12 はブラウザ本来の機能のままです。

## プライバシー

- 選択したゲームファイルはブラウザ内でのみ読み込み・処理され、サーバーにアップロードまたは送信されることはありません。
